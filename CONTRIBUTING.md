# Contributing to AdGrowth Lab

Thank you for contributing to AdGrowth Lab's open-source TikTok advertising intelligence ecosystem!

## How to Contribute
1. **Report Live Cases**: If you discover new Pangle traffic leak patterns, policy updates, or VCC BIN changes, open an issue using the [Diagnostic Intake Form](.github/ISSUE_TEMPLATE/01_troubleshooting_case.yml).
2. **Submit Pull Requests**: Ensure all test suites pass with 100% coverage prior to opening a PR.
3. **Ecosystem Resource**: Check the [AdGrowth Lab Web Hub](https://adgrowth-lab.github.io/) for cross-repo updates.
